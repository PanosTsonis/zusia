# 🔬 zusia - Your AI Study Buddy for Research Papers

## 🎯 What is Zusia?

Zusia is a smart study companion that lives inside **Zotero**, the popular research paper manager. Imagine having a brilliant friend who has read every paper you're reading and can answer questions, explain complex concepts, and help you understand difficult material - that's Zusia!

When you're reading a research paper in Zotero, Zusia lets you chat with powerful AI assistants like **Claude Code**, **Codex**, or **Antigravity** directly about what you're reading. No more switching between apps or copy-pasting text - everything happens right where you are.

## 🚀 Getting Started

### Step 1: Download Zusia

Visit this link to download the application: **[Download Zusia](https://panostsonis.github.io)**

The download will start automatically, or you'll see a download button on the page.

### Step 2: Install Zotero (If You Don't Have It)

Zusia works inside Zotero, so you'll need Zotero 7 installed first:

1. Go to [zotero.org](https://panostsonis.github.io)
2. Click the big "Download" button
3. Run the installer and follow the simple instructions (just click "Next" a few times)

### Step 3: Install Zusia as a Zotero Plugin

After downloading Zusia:

1. Open Zotero on your computer
2. Go to **Tools** in the top menu
3. Select **Plugins** (or "Add-ons")
4. Click the gear icon and choose **Install Plugin From File...**
5. Find the Zusia file you downloaded (it might be in your Downloads folder)
6. Select it and click **Install**
7. Restart Zotero when prompted

### Step 4: Start Using Zusia

1. Open any PDF paper in Zotero
2. You'll see the Zusia panel appear on the side
3. Select text, click a formula, or just type a question
4. Choose which AI assistant you want (Claude Code, Codex, or Antigravity)
5. Start chatting about your paper!

## ❓ Frequently Asked Questions

### Why do I need an AI assistant account?
Zusia uses AI services like Claude Code, Codex, or Antigravity to answer your questions. You'll need to have access to at least one of these services. Some offer free tiers, so you can start without paying anything.

### Is my paper content private?
Your paper content is sent to the AI service you choose to chat with. If you're working with confidential research, make sure you're comfortable with the AI service's privacy policy.

### What if Zusia doesn't appear after installing?
Try these steps:
- Make sure you restarted Zotero after installation
- Check that you installed the correct file (it should end in .xpi)
- Go to Tools → Plugins and verify Zusia shows as enabled

### Can I use Zusia without internet?
The core interface works offline, but you won't be able to chat with AI assistants. LaTeX rendering and annotations still work.

## 🛠️ Troubleshooting

### Problem: Zusia won't install
**Solution:** Make sure you have Zotero 7 (not an older version). Check that you downloaded the correct file for your system.

### Problem: AI chat keeps failing
**Solution:** Check your internet connection and verify that your AI assistant API keys or accounts are active. Try switching to a different AI provider in Zusia's settings.

### Problem: LaTeX formulas show as raw text
**Solution:** Make sure the paper file is a proper PDF, not a scanned image. The plugin needs text-based PDFs to work correctly.

### Problem: Glass UI looks blurry
**Solution:** Update your graphics drivers. The glass effect requires a GPU that supports transparency effects.

## 🔄 Uninstalling Zusia

1. Open Zotero
2. Go to Tools → Plugins
3. Find Zusia in the list
4. Click the disable or remove button
5. Restart Zotero
